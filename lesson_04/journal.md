## Журнал команд

| №  | Команда                                                               | Что сделала                                                                                  | Безопасный пример                                                                                                       |
| -- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1  | `mkdir -p ../sorted/{docs,images,logs,data}`                          | Создала каталоги `docs`, `images`, `logs` и `data` внутри `sorted`.                          | `mkdir -pv ../sorted/{docs,images,logs,data}` — показывает создаваемые каталоги.                                        |
| 2  | `mv "my report.txt" my-report.txt`                                    | Переименовала файл `my report.txt` в `my-report.txt`.                                        | `ls -l "my report.txt"` — проверяет наличие исходного файла перед переименованием.                                      |
| 3  | `mv report-*.txt my-report.txt ../sorted/docs/`                       | Перенесла отчёты и файл `my-report.txt` в каталог `sorted/docs`.                             | `ls report-*.txt my-report.txt` — показывает файлы, которые попадут под маски.                                          |
| 4  | `mv *.{jpg,png} ../sorted/images/`                                    | Перенесла изображения форматов JPG и PNG в `sorted/images`.                                  | `ls *.{jpg,png}` — показывает подходящие изображения.                                                                   |
| 5  | `mv app.log app.log.[12] error.log ../sorted/logs/`                   | Перенесла журналы приложения и журнал ошибок в `sorted/logs`.                                | `ls app.log app.log.[12] error.log` — проверяет список файлов перед переносом.                                          |
| 6  | `cp *.csv ../sorted/data/`                                            | Скопировала CSV-файлы из `inbox` в `sorted/data`, сохранив оригиналы.                        | `ls *.csv` — показывает CSV-файлы для копирования.                                                                      |
| 7  | `rm -v *.bak`                                                         | Удалила резервные копии с расширением `.bak`.                                                | `ls *.bak` — показывает файлы, которые будут удалены; `rm -i *.bak` — запрашивает подтверждение удаления каждого файла. |
| 8  | `find ~/files-lab -type f -size +1M`                                  | Нашла файлы размером больше 1 МиБ. После проверки размера удалила нужный файл командой `rm`. | `find ~/files-lab -type f -size +1M -exec ls -lh {} \;` — выводит размеры найденных файлов без удаления.                |
| 9  | `find ~/files-lab/inbox -type f -mtime +30 > ~/files-lab/answers.txt` | Записала в `answers.txt` список файлов, которые не изменялись более 30 суток.                | `find ~/files-lab/inbox -type f -mtime +30` — показывает список без записи в файл.                                      |
| 10 | `ls -A` и `cat .settings >> ~/files-lab/answers.txt`                  | Нашла скрытые файлы и дописала содержимое `.settings` в `answers.txt`.                       | `cat .settings` — показывает содержимое скрытого файла без изменения `answers.txt`.                                     |
| 11 | `ls -lhS ../sorted/images`                                            | Вывела изображения в порядке убывания размера с удобным отображением размеров.               | `ls -lhS ../sorted/images` — только показывает список и ничего не изменяет.                                             |
| 12 | `locate os-release \\| head -1 >> ~/files-lab/answers.txt`            | Нашла первый путь к файлу `os-release` и дописала его в `answers.txt`.                       | `locate os-release \\| head -1` — показывает первый найденный путь без записи в файл.                                   |
