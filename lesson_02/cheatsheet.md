# Шпаргалка по командам Linux: файлы, маски, поиск и справка

| Команда | Назначение | Безопасный пример | Опасный вариант и чем он опасен |
|---|---|---|---|
| `pwd` | Показывает текущий каталог. | `cd ~/files-lab && pwd` — проверяет, где выполняются команды. | Выполнять команды с удалением, не проверив каталог: можно затронуть не те файлы. |
| `ls` | Показывает файлы и каталоги. | `ls -lah ~/files-lab/inbox` — показывает список, включая скрытые файлы, и размеры. | `ls` сам по себе не удаляет данные; опасно считать, что он проверил маску, если нужные файлы не попали в вывод. |
| `mkdir` | Создаёт каталоги. | `mkdir -pv ../sorted/{docs,images,logs,data}` — создаёт структуру и показывает созданные каталоги. | `mkdir -p /важный/путь/...` — можно случайно создать ненужную структуру в системном или чужом каталоге. |
| `touch` | Создаёт пустой файл или обновляет время изменения существующего. | `touch ~/files-lab/empty.txt` — создаёт пустой файл. | `touch` по неверно указанному пути может изменить время не того файла; обычно данные не удаляет, но может повлиять на сортировку и автоматизацию. |
| `cp` | Копирует файлы. | `cp -i *.csv ../sorted/data/` — спрашивает перед перезаписью. | `cp data.csv important.csv` без проверки пути может перезаписать существующий `important.csv`. |
| `mv` | Перемещает или переименовывает файлы. | `mv -i *.{jpg,png} ../sorted/images/` — спрашивает перед перезаписью. | `mv * ../` — перемещает все подходящие элементы из текущего каталога в родительский, что может нарушить структуру проекта. |
| `rm` | Удаляет файлы без корзины. | `ls *.bak`, затем `rm -i *.bak` — сначала показывает совпадения, затем спрашивает подтверждение. | `rm * .bak` — из-за пробела `*` и `.bak` становятся отдельными аргументами; `*` может удалить все обычные файлы текущего каталога. |
| `find` | Ищет файлы и каталоги по условиям. | `find ~/files-lab -type f -size +1M` файлы размером больше 1 МиБ | `find ~/files-lab -type f -name '*.txt'` без ограничения каталога может выдать много посторонних результатов. |
| `locate` | Ищет пути по индексной базе файлов. | `locate os-release \| head -1` — выводит первый найденный путь; база может быть устаревшей. | `locate '*.log' \| xargs rm` — опасно передавать результаты поиска на удаление: пути могут быть неожиданными или содержать пробелы. |
| `man` | Открывает справку по команде. | `man ls` — читает руководство; нажмите `/` и введите слово для поиска, `q` — выход. | Вводить команды из примеров справки без понимания их действия и путей может привести к изменению или удалению данных. |
| `man -k` | Ищет команды и разделы справки по ключевому слову. | `man -k copy` — показывает справочные страницы, связанные с копированием. | Выбирать случайную команду только по совпадению слова и запускать её с правами администратора — риск выполнить неподходящее действие. |
| `head` | Показывает начало файла или первые строки вывода команды. | `head -n 2 ~/files-lab/answers.txt` — читает первые две строки. | `head -n 5 файл > файл` — перенаправление сначала обнуляет исходный файл, поэтому данные будут потеряны. |
| `cat` | Выводит содержимое файла; может объединять файлы. | `cat ~/files-lab/answers.txt` — показывает содержимое файла, если он существует. | `cat new.txt > important.txt` — перезаписывает `important.txt`, даже если в `new.txt` пусто. |
| Маски `*`, `?`, `[ ]` | Выбирают имена файлов по шаблону: `*` — любое число символов, `?` — один символ, `[ ]` — один символ из набора. | `ls ~/files-lab/sorted/images/photo-0[12].*` — показывает файлы `photo-01.*` и `photo-02.*`, если они есть. | `rm ~/files-lab/sorted/images/photo-0[1-9].*` — удалит все совпавшие файлы с номерами от 1 до 9; сначала проверьте маску через `ls`. |
| `ls -lhS` | Показывает файлы с удобными размерами, сортируя по размеру от большего к меньшему. | `ls -lhS ~/files-lab/sorted/images` — только отображает список. | Сам `ls -lhS` не изменяет файлы; риск возникает, если по непроверенному списку затем выполнить массовое удаление. |
