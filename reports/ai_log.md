# Использованные запросы к chatgpt

## Запрос для формирования файла os-types
```
Мне нужно создать краткий md файл Типы операционных систем

В нём должна быть не только теория, но и классификация ОС, установленной на моем ноутбуке (windows 11 home).

Классифицируй версию Windows 11 home по следующим признакам:
• назначение: настольная, серверная, мобильная, встроенная или ОС реального времени;
• число задач: однозадачная или многозадачная;
• работа с пользователями: однопользовательская или многопользовательская по возможностям ОС;
• интерфейс: графический, командный или комбинированный;
• сфера применения: общего назначения или специализированная;
• поддержка сети: локальная/сетевая работа, наличие сетевых возможностей.
Для каждого признака напишите: «тип → почему так считаю → какое наблюдение на моём ПК это подтверждает». Например, наличие одновременно работающих процессов можно использовать как одно из доказательств многозадачности.

Сравните минимум 4 ОС:
• Windows 11 home;
• Manjaro
• Android;
• ucos (ОС реального времени).
Сделать таблицу со столбцами

ОС
Где применяется
Тип по назначению
Многозадачность
Интерфейс
Ключевое отличие

После таблицы ответьте в 4–6 предложениях: почему нельзя считать, что все операционные системы предназначены для одних и тех же задач?
```
